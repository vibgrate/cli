# Vibgrate CLI 2026.909.1

_Released 2026-09-09_

This release of the Vibgrate CLI includes several enhancements and fixes aimed at improving the functionality and usability of the vg command. Key updates include improved reporting for the vg review command and new features for pushing evidence to Vibgrate Cloud.

## What changed

### New

- `vg evidence push` now sends every frozen release manifest along with the bundle's signature envelope and timestamp when `--result` points at a bundle directory.
- `vg review` now reviews changes against HEAD or a specified base, reporting various findings and allowing for output in multiple formats.
- `vg review` receipts are now signed, and a new command verifies the receipt offline.

### Improved

- vg review now reports a changed write route with no authorization guard as an unknown when there are too few classified peer routes.

### Fixed

- The documentation for `vg review` now accurately reflects the command's exit codes.
- vg review no longer reports 'no test reaches this file' for documentation or dependency changes.
- vg show arch now allows for scrolling and zooming, improving the usability of the map.
