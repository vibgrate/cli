# Vibgrate CLI 2026.916.2

_Released 2026-09-16_

This release of the Vibgrate CLI includes enhancements to the `vg review propose` command, providing clearer information about protocols and usage metrics. Additionally, a fix has been implemented for the VG Code invent-check functionality.

## What changed

### Improved

- `vg review propose` now states the loop vs one-shot protocol up front and includes the cited file, allowing a PatchIR to fit within the existing 5-step cap.

### Changed

- `vg review propose --json` now includes `usage` metrics for the agent loop, enabling hosts to tally steps and tokens.

### Fixed

- VG Code invent-check now allows a helper declared in the same edit while still blocking calls to symbols not in the graph.
