# Vibgrate CLI 2026.910.2

_Released 2026-09-10_

This release of the Vibgrate CLI introduces enhancements to the architecture visualization and adds new functionality for workspace management. Users can expect improved clarity in the architecture display and easier access to specific components.

## What changed

### New

- `vg lsp` now serves the architecture map page, a package slice, and a symbol inspector for easier workspace navigation.

### Improved

- `vg show arch` now displays columns and cards from the architecture classify file, enhancing visibility of roles, purposes, and intents.
- UI pages are now organized under UI / Endpoint, with empty columns hidden for a cleaner presentation.
- Call edges are now lifted onto the collapsed card, allowing the inspector to show actual page calls.
