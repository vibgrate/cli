# Vibgrate CLI 2026.1029.1

_Released 2026-10-29_

This release of the Vibgrate CLI includes important fixes for dependency handling in Gradle projects and updates the Node.js version requirement. Users should review these changes to ensure compatibility with their projects.

## What changed

### Changed

- The Vibgrate CLI now requires Node.js 24 or later; Node.js 22 is no longer supported.

### Fixed

- `vg sbom export` now correctly marks Gradle `testImplementation`, `testRuntimeOnly`, or `testCompileOnly` dependencies as development dependencies.
