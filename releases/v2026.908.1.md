# Vibgrate CLI 2026.908.1

_Released 2026-09-08_

This release introduces context compression for AI coding agents, enhancing the efficiency of tool output without requiring new commands. Additionally, a stray warning during model loading has been resolved.

## What changed

### New

- Context compression for AI coding agents allows for lossless compression of tool output, with no new commands to learn.
- New commands such as `vg serve --compress`, `vg savings`, and `vg show savings` provide detailed insights and functionality related to compression.

### Fixed

- The stray warning from the embedding runtime (onnxruntime) during model loading on Hyper-V, WSL2, and similar hosts has been removed.
