# Vibgrate CLI 2026.819.2

_Released 2026-08-19_

This release of the vg CLI includes important fixes and changes aimed at improving the user experience and accuracy of model status checks and architecture scoring. Notably, the interaction with the Ollama desktop app has been streamlined.

## What changed

### Changed

- Code Modes (Spark / Flow / Forge) are now first-party GGUF on embedded llama.cpp only, with no Ollama fallback.

### Fixed

- Checking model status no longer wakes the Ollama desktop app.
- Architecture scoring no longer misclassifies a Vue/React Client.WebApp as a backend layered stack.
