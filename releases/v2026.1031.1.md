# Vibgrate CLI 2026.1031.1

_Released 2026-10-31_

This release of the Vibgrate CLI includes several important fixes related to the handling of development dependencies across different package managers. The updates improve the accuracy of the dependency scanning and export processes.

## What changed

### Fixed

- `vg sbom export` now correctly lists Cargo dev and build crates as direct development dependencies.
- `vg sbom export` treats packages in Pipfile dev-packages or specific requirements files as development dependencies.
- `vg scan` and `vg sbom export` recognize .NET PackageReference with PrivateAssets set to all as development dependencies.
- `vg scan` now reads Elixir dependencies in mix.exs that declare keyword options, accurately identifying development and optional dependencies.
