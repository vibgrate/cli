# Vibgrate CLI 2026.802.1

_Released 2026-08-02_

This release of the Vibgrate CLI introduces an optional local relevance module that enhances the vg command's ability to connect user queries with relevant code. Additionally, several improvements have been made to the code handling and session management for better user experience.

## What changed

### New

- vg can now use an optional local relevance module to improve query relevance.
- A new 'vg module' command allows for the installation, removal, and inspection of the relevance module.
- vg code sessions now support per-turn agent modes and image attachments.
- A new /compact command in vg code condenses long conversations into checkpoints.

### Improved

- vg now fuses lexical and semantic rankings for smarter answers.
- vg code routes by model capability to enhance compatibility with various models.

### Changed

- Attaching images to models that cannot see them now provides a clear notice.

### Fixed

- VG Code now works with any model, improving compatibility with local and various models.
