# Vibgrate CLI 2026.1103.2

_Released 2026-11-03_

This release of the Vibgrate CLI introduces several new features and fixes across various commands, enhancing the handling of dependencies and improving profiling capabilities. Notable updates include support for additional package formats and improved logging options for better traceability.

## What changed

### New

- `vg code --provider grok-build` allows running tasks on Grok Build with enhanced context injection.
- `vg code --profile` provides detailed profiling output, including step-by-step execution and logging options.
- `vg sbom export` now includes development dependencies from various package formats, including `pubspec.yaml`, `composer.lock`, and `Pipfile.lock`.
- `vg scan` and `vg sbom export` now support Maven dependencies declared in `pom.xml` profiles.
- `vg sbom export` now reads .NET `packages.lock.json`, including NuGet packages and their dependency edges.
- `vg sbom export` includes PHP packages from `composer.lock`, marking development packages appropriately.

### Improved

- `vg code --stream-json` protocol version 6 improves transcript brevity and agent response times.

### Fixed

- `vg scan` and `vg sbom export` now correctly handle Cargo crates and Gemfile dependencies, ensuring accurate reporting.
- `vg sbom export` correctly marks lockfile-only npm packages and handles various group scenarios in Gemfile.
- `vg scan` expands PEP 735 entries in `pyproject.toml` and reads `replace` directives in `go.mod`.
