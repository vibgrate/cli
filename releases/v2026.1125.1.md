# Vibgrate CLI 2026.1125.1

_Released 2026-11-25_

This release of the Vibgrate CLI includes a fix for the vg scan command, ensuring it correctly reads version 1 Swift Package.resolved files. This change allows URL-declared packages to use their pinned versions instead of the declared lower bounds.

## What changed

### Fixed

- vg scan now reads version 1 Swift Package.resolved files, so a URL-declared package uses its pinned version instead of the declared lower bound.
