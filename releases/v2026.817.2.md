# Vibgrate CLI 2026.817.2

_Released 2026-08-17_

This release of Vibgrate CLI introduces new commands for managing app translations and enhances architecture detection capabilities. Several fixes improve the accuracy of architectural role assignments and boundary violation reporting during scans.

## What changed

### New

- Manage your app's translations from the command line with `vg locale`, including commands for configuration, pushing, pulling, and checking status.
- Scan now confirms a file's architectural role based on parsed syntax, improving accuracy regardless of file location.
- Architecture scans classify folders based on their contents and inherit classifications to unclassified sources when appropriate.
- Architecture detection identifies project types using composable knowledge packs, allowing for more precise classifications.

### Improved

- Architecture detection now classifies each project individually, rather than labeling multi-project repositories as monorepos.

### Fixed

- Architecture roles now fire only for the frameworks a project actually uses, with confirmed roles remaining attached after an editor reload.
- `vg scan` now correctly prints and writes architecture boundary violations, which were previously omitted.

### Performance

- Scan now retrieves package versions over HTTP in parallel and utilizes a 4-hour cache for improved efficiency.
