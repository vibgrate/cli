# Vibgrate CLI 2026.803.4

_Released 2026-08-03_

This release of the Vibgrate CLI includes important fixes for the `vg code` command, enhancing error reporting for various backend issues. Users can expect clearer feedback when encountering gateway failures and other HTTP errors.

## What changed

### Fixed

- `vg code` now correctly identifies gateway failures, providing appropriate error messages for different HTTP status codes.
- When an endpoint returns an HTML error page instead of JSON, the title of the error page is now displayed for better clarity.
