# Vibgrate CLI 2026.916.1

_Released 2026-09-16_

This release of the vg CLI includes several important fixes and new features aimed at improving the review process and architecture visualization. Notably, enhancements to the review commands and architecture map provide better usability and clarity.

## What changed

### Changed

- `vg review propose` now reuses the VG Code agent loop for PatchIR dry-runs, with improved failure handling.
- `vg review` now honors `.vibgrate/review/` team files and includes options for `--in-place`, `--local`, and `--loop`.
- The architecture map's fallback view now displays a plain package/file topology instead of a reimplementation of the Architecture module's logic.
- The architecture board now organizes projects into UI, Application, and Data-Infra lanes for better clarity.

### Fixed

- Homebrew, Scoop, Helm, and Docker Hub now have a release pipeline, ensuring consistent access to the vg CLI.
- The architecture map's Projects view no longer lists CI jobs and other toolchain artifacts as top-level projects.
- Code Mode now trims padded tool paths and resolves unique matches for file names more effectively.
- Code Mode maps spaced and hyphenated tool names correctly before dispatching.
