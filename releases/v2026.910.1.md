# Vibgrate CLI 2026.910.1

_Released 2026-09-10_

This release of the vg CLI introduces several performance improvements and fixes, particularly around the local runtime and code map handling. Changes to command outputs and behavior enhance usability for developers working with package management and code analysis.

## What changed

### Improved

- vg serve, vg lsp, and vg code now share one local runtime for the code map, allowing for faster queries and reducing the likelihood of a dead runtime hanging the editor.

### Changed

- vg show arch now opens on a workspace map of packages and drills into a column slice instead of displaying every symbol as a card.

### Fixed

- vg drift --online no longer incorrectly reports a package as behind latest when the installed version is newer than the npm latest dist-tag.

### Performance

- When the local runtime (vgd) is running, it is now the only process that holds the code map, improving efficiency for commands like vg lsp, vg serve, and vg code.
- Switching branches in the local runtime no longer answers from the previous branch's code map, and closing a workspace unregisters it to free graph slots.
