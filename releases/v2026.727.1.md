# Vibgrate CLI 2026.727.1

_Released 2026-07-27_

This release of the Vibgrate CLI introduces several enhancements to local inference, coding metrics, and model management. Key updates include improved performance for multi-turn coding and new API features for enterprise use.

## What changed

### New

- Completed Approach B P0 with new features for patches, host-load/generate/status, and weight catalog integrity reporting.
- `vg code` now auto-routes to embedded inference when weights are installed, simplifying the process.
- Local llama.cpp maintains warm model sessions across turns, reducing time-to-first-token after load.
- Introduced `vg models coding-metrics` for enhanced coding metrics reporting.
- New dual-mode llm-host library API allows for flexible inference management.
- `vg llm-host serve` enables enterprise process isolation for inference.
- `vg models host-bench` measures local-inference arms with optional release gates.

### Improved

- Local coding quality and multi-turn speed have been enhanced with graph-aware TokenBias.
- Improved local coding setup UX with better reporting and model management.

### Changed

- `vg models install` and `vg models pull` now install dependencies in a single step.

### Fixed

- Resolved a multi-second stall on `vg serve` tool calls during map rebuilds.

### Security

- First-party GGUF catalog downloads are now pinned with sha256 integrity checks.
