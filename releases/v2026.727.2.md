# Vibgrate CLI 2026.727.2

_Released 2026-07-27_

This release of the Vibgrate CLI addresses an issue with memory reporting on macOS and Linux. The changes ensure that the available RAM is accurately reflected when using the vg models install and vg code commands.

## What changed

### Fixed

- Fixed Code Mode fit so vg models install and vg code no longer report 0 GiB free on macOS.
- Available RAM now uses reclaimable memory instead of bare free pages, improving accuracy on Linux.
- IDE/OS reserves are no longer double-counted against already-free RAM.
