# Vibgrate CLI 2026.725.1

_Released 2026-07-25_

This release of the Vibgrate CLI introduces several new features and improvements focused on security, performance, and usability. Key updates include enhanced shell isolation, new tools for failure recovery, and improved integration with the Fusion Runtime.

## What changed

### New

- vg daemon ensure starts the local Fusion Runtime daemon in the background when needed.
- vg code can now inspect the blast radius of a proposed change before applying it.
- vg code agents can apply multi-file PatchIR edits via the new apply_patch tool.
- vg daemon publish loads the workspace code map into the Fusion Runtime.
- The code map is now branch-aware, allowing for snapshots keyed by git branch.
- Federation discovery now records conservative bridge edges from OpenAPI $ref paths and Docker Compose build contexts.
- vg code can use a source-bearing Task Capsule for the first model context.
- Fusion Runtime continues with multi-root workspaces and a security-ladder execution environment.
- Project-context ingest for vg ask now includes various configuration files as secret-scrubbed document nodes.

### Improved

- VG Code search and impact tools now use the Fusion Runtime daemon graph when available.
- Interactive vg code refreshes the code map for uncommitted git changes before each task.

### Changed

- Interactive vg code now attaches to the local Fusion Runtime daemon instead of spawning a separate process.

### Fixed

- vg serve now repaints its live status in place in narrow terminals.

### Security

- L1 shell isolation is enforced using Seatbelt on macOS and bubblewrap on Linux, scoped to project roots.
