# Vibgrate CLI 2026.819.3

_Released 2026-08-19_

This release of the Vibgrate CLI includes important fixes that enhance the stability of the daemon and improve test code handling. Users should consider updating to benefit from these corrections.

## What changed

### Fixed

- -- vg daemon start now recovers from a stale daemon that holds the socket without answering.
- Test code no longer triggers architecture boundary violations, as files in test projects are excluded from layer-boundary checks.
