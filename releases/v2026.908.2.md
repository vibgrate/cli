# Vibgrate CLI 2026.908.2

_Released 2026-09-08_

This release of the Vibgrate CLI includes important fixes and a command name change for better clarity. Users should review the changes to ensure they are aware of the updated functionality.

## What changed

### Changed

- `vg show chart` has been renamed to `vg show arch`, reflecting the Architecture module's public name while maintaining the same flags and functionality.

### Fixed

- Context compression now functions correctly in the published build, allowing `vg serve --compress`, `vg savings --benchmark`, and `vg code` to report accurate compression results.
