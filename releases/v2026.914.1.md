# Vibgrate CLI 2026.914.1

_Released 2026-09-14_

This release of the Vibgrate CLI includes important fixes and enhancements to improve the scanning process and user experience. Notably, the new IAC scanning capabilities provide deeper insights into infrastructure security.

## What changed

### New

- Introduced --iac scanning to evaluate Terraform, Kubernetes, Helm, and Dockerfile configurations against security benchmarks.

### Improved

- The --iac scan now provisions the Architecture module on first use similarly to vg build, with better error reporting for install issues.

### Fixed

- The architecture map now retains job information from the last classify file during rebuilds.
- Resolved a Node MODULE_TYPELESS_PACKAGE_JSON warning that appeared with every vg command after the previous version.
