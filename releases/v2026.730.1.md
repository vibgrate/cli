# Vibgrate CLI 2026.730.1

_Released 2026-07-30_

This release of the Vibgrate CLI introduces enhancements to local file management and runtime reporting. It also lays the groundwork for future features related to model routing.

## What changed

### Changed

- The command vg lsp now reports the nearest real end-of-life dates for your runtimes, sourced from the Runtime Catalog data.
- The command vg code --stream-json now creates a local, append-only record of run proposals and outcomes in .vibgrate/run-outcomes.jsonl.

### Fixed

- The score-history and run-outcome files are now covered by the auto-managed .vibgrate/.gitignore, preventing them from being staged for commits.
