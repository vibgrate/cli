# Vibgrate CLI 2026.1110.1

_Released 2026-11-10_

This release of the Vibgrate CLI includes several important fixes and enhancements to improve the accuracy and reliability of scans across various package managers and Docker images. Notably, it now supports a wider range of Dockerfile formats and improves handling of dependencies in multiple languages.

## What changed

### New

- vg scan now reads every Dockerfile and Compose file in a directory, including various naming conventions.
- vg scan and vg sbom export now read npm-shrinkwrap.json as an npm lockfile.

### Changed

- The dependency-scope docs table now describes the current Cargo.lock and uv.lock behaviour.

### Fixed

- The published CLI now installs smol-toml 1.9.0, clearing a moderate advisory in that dependency.
- Docker image references with a registry port or content digest now retain the image name and human version tag.
- Docker scans now retain every tag of an image, reporting each tag with its own drift.
- Helm chart scans now keep dependency versions inside each dependency entry.
- Dart and Flutter scans now keep packages declared as a nested pubspec entry.
- Swift scans now read Package.swift dependencies written as version ranges.
- A blank or carriage-return-only .gitignore line no longer hides lockfiles from the lockfile check.
- Cargo dependencies declared with workspace = true inherit their version from the workspace root.
- Images from registries other than Docker Hub now retain the registry in their name.
- FROM ${BASE_IMAGE} and similar references now use the ARG defaults declared before them.
- vg scan now reads Dockerfile FROM lines written in lowercase or indented.
- In multi-stage Dockerfiles, FROM references pointing to earlier build stages are no longer reported as Docker Hub images.
- Helm dependencies using the same chart under different aliases are kept as separate rows.
- The latest Swift, Dart, and PHP versions used for runtime drift now come from the release catalog.
- Swift framework detection now matches packages by their repository name.
