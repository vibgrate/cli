# Vibgrate CLI 2026.819.1

_Released 2026-08-19_

This release of the Vibgrate CLI includes important fixes to improve the accuracy of the code map and workspace picker. The adjustments ensure that specified exclusions are respected and that hidden directories do not interfere with the scanning process.

## What changed

### Fixed

- `vg build` now honors `exclude` from `vibgrate.config.json`, preventing specified fixture trees from appearing in the code map and generated area skills.
- `vg scan` and the code graph no longer include agent worktrees or other hidden folders, eliminating extra packages from the workspace picker.
