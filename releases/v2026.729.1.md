# Vibgrate CLI 2026.729.1

_Released 2026-07-29_

This release of the Vibgrate CLI introduces performance improvements for loading large code maps and optimizes default builds for speed and disk usage. The changes enhance the overall efficiency of the vg command while maintaining compatibility with existing formats.

## What changed

### Changed

- Default builds are faster and use less disk space, as the local application store now retains only the compact binary snapshot.
- The standard graph.json format remains unchanged and is still produced for sharing or committing the map.

### Performance

- Large code maps now load about 2.6x faster due to a new compact binary snapshot that is automatically used for queries and sessions.
