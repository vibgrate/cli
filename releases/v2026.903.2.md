# Vibgrate CLI 2026.903.2

_Released 2026-09-03_

This release of the Vibgrate CLI includes significant updates to the architecture module, improving the accuracy of purpose checks against a gold standard. Various adjustments have been made to enhance the precision of callable classifications across multiple languages.

## What changed

### Changed

- The architecture module's purposes are now validated against a hand-labelled gold set, improving precision and recall metrics for various functions.
- Inbound cues now score the new additive 'respond' purpose instead of outbound 'network_io'.
- Rails and Django methods are now accurately read according to their actual behavior.
- Python decorators are now stored beside the signature, allowing for better recognition of controller methods.
- Tests no longer persist or call out through their mocks, reducing false positives.
- React state hooks are no longer considered rendering calls.
- Interface and abstract methods are excluded from body scans.
