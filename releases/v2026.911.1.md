# Vibgrate CLI 2026.911.1

_Released 2026-09-11_

This release of the Vibgrate CLI introduces improvements to the architecture map display and expands the scanning capabilities to include external surfaces accessed by your code. These changes enhance both usability and the comprehensiveness of the scans.

## What changed

### New

- Scans now inventory external surfaces your code reaches, including vendor APIs, AI models, MCP servers, and third-party SaaS, in addition to the packages in your lockfile.

### Fixed

- The architecture map opened by vg show arch now correctly displays its package and card canvas, resolving an issue where nodes were hidden behind a loading banner.
