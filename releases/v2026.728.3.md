# Vibgrate CLI 2026.728.3

_Released 2026-07-28_

This release of the Vibgrate CLI includes a fix for the vg models uninstall command, enhancing its functionality by ensuring it removes LM Studio and GGUF models from disk, in addition to Ollama. The command now automatically detects the runtime from the installed fleet.

## What changed

### Fixed

- vg models uninstall now removes LM Studio and GGUF models from disk, not just Ollama.
