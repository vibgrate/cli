# Vibgrate CLI 2026.803.1

_Released 2026-08-03_

This release of the Vibgrate CLI introduces an optional local relevance module that enhances question resolution for specific domains. It also includes improvements to model interactions and new commands for better session management.

## What changed

### New

- vg can now use an optional local relevance module to improve question resolution for specific domains.
- New 'vg module' command allows for installation, removal, and inspection of the relevance module.
- vg code sessions now accept per-turn agent modes and image attachments over the stream-json submit frame.
- New /compact command in vg code condenses long conversations into a checkpoint.

### Improved

- vg now fuses lexical and semantic rankings for smarter answers.
- vg Code routes by model capability, automatically using the text tool protocol for models without native tool calling.

### Changed

- Attaching images to a model that cannot see them now shows a clear notice instead of silently ignoring them.

### Fixed

- VG Code now works with any model, including those without native tool calling.
