# Vibgrate CLI 2026.818.2

_Released 2026-08-18_

This release of the Vibgrate CLI includes performance improvements that enhance the efficiency of the `vg ask` command and the language server's interaction with the local runtime. These changes aim to reduce unnecessary delays and resource usage during operation.

## What changed

### Performance

- `vg ask` now waits for the local runtime to finish the semantic index, improving response times for the first question after a scan.
- The language server no longer watches the workspace when the local runtime is active, reducing redundant rebuilds and improving edit detection.
