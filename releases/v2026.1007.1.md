# Vibgrate CLI 2026.1007.1

_Released 2026-10-07_

This release of the Vibgrate CLI introduces new features for risk scoring and improved documentation for existing commands. Several fixes enhance error reporting and the handling of package components.

## What changed

### New

- driftBudget now accepts maxRiskScore and maxRiskWorseningPercent, with local vg scan reporting those limits as not evaluated.
- vg scan --summary-out writes a small JSON summary of the DriftScore for CI steps, with new outputs for drift-score, risk-level, and score-delta.

### Improved

- vg build --attest and vg build --verify are now documented, detailing the signing process and error messages.
- Documentation for vg build now explains how GitHub Actions uses pins in the code map.
- vg sbom export and vg scan --format json now document package digest fields and clarify project and solution identifiers.

### Changed

- The npm page for Vibgrate CLI now links to the CLI product page and describes how a scan scores drift and exposure separately.

### Fixed

- vg evidence and vg build --attest now exit with clear error messages when the output file cannot be serialized or written.
- vg sbom export retains one component when multiple projects resolve the same package, providing a warning for dropped dependencies.
