# Vibgrate CLI 2026.727.4

_Released 2026-07-27_

This release of the vg command-line scanner includes updates to Code Modes and improvements to quality gates for library documentation. Users can expect better handling of API queries and more accurate ratings for package import impacts.

## What changed

### Improved

- -- library_docs quality gate no longer marks README-only answers as sufficient for focused API queries.
- The get_facts and guide_node commands now accept 'pick' for ambiguous symbols.
- The upgrade_impact command rates wide import fan-out as moderate even when the package is current.

### Changed

- Code Modes (Spark, Flow, and Forge) now run on the Vibgrate model manager with first-party weights, including Forge’s 14B pack.
