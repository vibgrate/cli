# Vibgrate CLI 2026.731.1

_Released 2026-07-31_

This release of the Vibgrate CLI introduces enhancements to architecture layer summaries and improves the reporting of vulnerable-symbol reachability findings. These updates aim to provide clearer insights and facilitate easier navigation within codebases.

## What changed

### Improved

- Architecture layer summaries now include a capped sample of the source files classified into each layer.
- The language server exposes a new `vibgrate/architecture` request, allowing for per-project or whole-workspace architecture and tech-stack detail retrieval.
- Manifest and lockfile paths are now included in the monorepo project list for better context.
- Vulnerable-symbol reachability findings now provide structured code sites, including file and line information when known.
- Editors and reports can now jump directly to the import or use site that evidences a package is reached.
