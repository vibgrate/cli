# Vibgrate CLI 2026.1112.1

_Released 2026-11-12_

This release of the vg command-line scanner includes several important fixes and a new feature for Elixir umbrella apps. The updates enhance the accuracy of scans for various dependency configurations across multiple languages.

## What changed

### New

- vg scan now links Elixir umbrella apps, recording dependencies between sibling projects in the scan.

### Fixed

- vg scan now treats a newer toolchain line in go.mod as the Go runtime, ensuring lag and end-of-life align with the version the module builds with.
- Gradle scans now include Android and Kotlin dependency configurations, covering various test and production variants.
- vg scan now scores npm package aliases, including scoped packages and aliases without version ranges.
- Maven dependencies that use project.version, project.groupId, or the parent coordinate are now retained in vg scan and SBOM export.
